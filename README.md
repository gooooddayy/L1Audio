# L1Audio
一站式本地音频处理工具集 — 分析、增强、歌词转换、编辑，全部本地运行，无需联网<br>
【WorkBuddy】index.zip https://workbuddy.link/p/2dfsuX7AsjTBRRKgnARhkx?ext2=copy_link<br>
音频质量分析<br>
分析音频文件的格式、采样率、频谱、动态范围，检测假无损与过采样<br>
<br>
音频增强器<br>
提升音频音质，支持多种增强模式与输出格式转换<br>
<br>
歌词精度转换<br>
LRC 歌词时间戳在 2 位与 3 位毫秒精度间互转，支持实时转换与导出<br>
<br>
音频分割编辑<br>
可视化波形编辑 — 分割、淡入淡出、删除片段、变速播放、导出 WAV<br>
